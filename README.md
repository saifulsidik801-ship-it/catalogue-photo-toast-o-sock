TOAST-O-SOCK — a studio catalogue photograph of an impossible gadget: a chrome two-slot toaster that toasts socks. One golden-brown toasted sock pops out of the slot, still steaming, with a single folded sock beside it as the only accessory. The absurd job reads at a glance; the only text is the product's own engraved brand plate.

## Run it

```sh
python3 main.py
```

Writes the photograph to `/output/entry.png` (JPEG, 1024×1024, 85,270 bytes — inside the 1 MiB / 1024×1024 gate). No network needed.
